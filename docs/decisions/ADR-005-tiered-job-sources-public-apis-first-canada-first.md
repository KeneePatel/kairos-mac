# ADR-005: Tiered job sources, public APIs first, Canada first

## Status
Accepted 2026-10-19, with the approved spec.

## Date
2026-10-19

## Context
The preference or inherited choice this settles is cross-checked in SPEC.md §2; the requirement it serves is in the SPEC section named in the decision.

## Decision
Tier A ATS APIs on by default; tier B Adzuna (`ca` before `us`); tier C WebKit runners opt-in (Indeed Canada, Job Bank and others).

## Alternatives considered
Playwright; paid scraping APIs; a JobSpy sidecar.

## Consequences
None recorded beyond the decision itself.
