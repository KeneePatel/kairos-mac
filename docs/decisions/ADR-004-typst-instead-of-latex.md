# ADR-004: Typst instead of LaTeX

## Status
Accepted 2026-10-19, with the approved spec.

## Date
2026-10-19

## Context
The preference or inherited choice this settles is cross-checked in SPEC.md §2; the requirement it serves is in the SPEC section named in the decision.

## Decision
A bundled Typst CLI with JSON-driven templates.

## Alternatives considered
LaTeX/Tectonic (escaping, compile failures, font hacks); WebKit HTML printing (zero binaries, fiddly pagination; the fallback); CoreText drawing.

## Consequences
None recorded beyond the decision itself.
