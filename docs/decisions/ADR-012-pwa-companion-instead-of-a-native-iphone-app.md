# ADR-012: PWA companion instead of a native iPhone app

## Status
Accepted 2026-10-19, with the approved spec.

## Date
2026-10-19

## Context
The preference or inherited choice this settles is cross-checked in SPEC.md §2; the requirement it serves is in the SPEC section named in the decision.

## Decision
A framework-free PWA on Supabase, hosted on GitHub Pages (the repo is public).

## Alternatives considered
Native iOS (needs the paid program to reach friends' phones); Expo (back to Node and tunnels or a dev account).

## Consequences
Works on any phone or desktop, including Windows friends.
